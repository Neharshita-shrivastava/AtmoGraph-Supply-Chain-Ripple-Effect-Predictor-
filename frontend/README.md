# AtmoGraph Frontend

React + Vite dashboard prototype for **AtmoGraph – Supply Chain Ripple Effect Predictor**.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open the terminal and run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Included screens/components

- Supply chain overview dashboard
- Interactive sample supply-network map (click a node to inspect it)
- Disruption intelligence list
- Industry exposure indicators
- Quick scenario simulator (demo-only illustrative output)

## Important

The dashboard currently uses hard-coded sample data for the fictional **TechNova Electronics** business. It is a frontend prototype; no FastAPI, Neo4j, or ML model is connected yet. Replace the sample data and connect API calls when your backend is ready.
